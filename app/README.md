#  Application Machine Learning Multi-Pages (Streamlit)

## Description
Cette application web a été développée avec **Streamlit** dans le cadre du TP de déploiement.  
Elle permet de :

- charger un dataset CSV
- explorer les données
- entraîner un modèle de machine learning
- effectuer des prédictions

L'application est organisée en **plusieurs pages** :
- Data
- Training
- Prediction

---

#  Technologies utilisées

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---
### Logs

L'application enregistre certains événements importants dans un fichier `app.log`
comme les tentatives de connexion et les actions principales.
Cela permet de faciliter le débogage et le suivi de l'activité.
